# 英語リズム学習支援ツール(MVP)

`requirements.md` の 3.1 節(MVP)に対応する実装です。ブラウザ上でプロソディ(内容語/機能語、強形/弱形)を表示し、
学生が発話を録音して音量カーブ(RMS)を確認、音声認識との簡易比較フィードバックを得たうえで、
匿名化した数値データをサーバーに保存します。音声データそのものは保存しません(要件定義 3.4 節)。

## 構成

```
prosody/
├── requirements.md      # 要件定義書
├── backend/
│   ├── main.py           # FastAPI アプリ(API + フロントエンド配信)
│   ├── requirements.txt  # Python依存パッケージ
│   └── prosody.db        # SQLite DB(初回起動時に自動作成)
└── frontend/
    ├── index.html
    ├── style.css
    ├── sentences.js       # 例文データ(15文、コード内配列で管理)
    └── app.js             # 録音・RMS解析・音声認識・送信ロジック
```

## セットアップ

Python 3.10 以降が必要です。

```bash
cd backend
python -m pip install -r requirements.txt
```

## 起動

```bash
cd backend
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

起動後、**Google Chrome** で `http://127.0.0.1:8000/` を開いてください(マイク録音・音声認識は
Web Speech API 依存のため Chrome 前提です)。

## 使い方(学生側フロー)

1. 学籍番号(匿名ID)を入力する。氏名は入力させない運用とすること。
2. 例文を選択し、プロソディ表示(内容語=大きく濃い文字、機能語=小さく薄い文字、弱形の強調表示)を確認する。
3. 「モデル音声を再生」でブラウザTTSの参考音声を聞く。
4. 「録音開始」でマイク入力を開始し、発話後「録音停止」を押す。
   - 録音中の音量(RMS)を50msごとにサンプリングし、停止後に平滑化してグラフ表示する。
   - 同時に Web Speech API で音声認識を行い、目標文と単語単位で比較する。
     - 内容語が認識されなければ「発音が不明瞭な可能性」、機能語が認識されなければ「弱形として自然な可能性」と表示する。
5. 「送信する」で、匿名ID・例文ID・音量カーブ(数値配列)・認識結果テキスト・タイムスタンプをサーバーへ送信する。
   録音した音声そのものはブラウザ内で破棄され、サーバーには送信されない。

## データの確認(教員向け・簡易)

MVPでは認証なしの簡易確認用エンドポイントのみを用意しています。授業外の環境で公開しないでください。

```
GET /api/submissions
GET /api/submissions?student_id=S23
GET /api/submissions?sentence_id=s01
```

## 例文セットの編集

`frontend/sentences.js` の `SENTENCES` 配列を編集してください。1文につき単語ごとに
`{ text, type: "content" | "function", ipaStrong, ipaWeak, note }` を指定します(`ipaWeak` がある単語のみ強形/弱形の対比表示が出ます)。

## Renderへのデプロイ

リポジトリルートの `render.yaml` を使って [Render](https://render.com/) にデプロイできます。

1. RenderでGitHubリポジトリを接続し、「Blueprint」からこのリポジトリを選択する
   (`render.yaml` が自動検出されます)。
2. デプロイ完了後、発行されたURL(`https://<service>.onrender.com/`)を**Google Chrome**で開く。

### 注意事項(本番運用前に必ず確認)

- **DBの永続化**: Renderの無料プランはファイルシステムが一時的で、再デプロイ・再起動のたびに
  `prosody.db` が消えます。データを残す場合はRenderの永続ディスク(有料)を追加するか、
  PostgreSQL等の外部DBに切り替えてください。
- **`/api/submissions` (GET) は認証なし**です。Renderにデプロイすると誰でもアクセスできる
  URLになるため、学外公開する場合は簡易Basic認証などのアクセス制御を追加することを強く推奨します。
- HTTPS化はRenderが自動で行います(要件定義5節の要件を満たします)。

## 未対応・今後の課題(要件定義 3.2/3.3/3.4 節を参照)

- 教員用ダッシュボード、例文編集UI、ピッチ解析、CSVエクスポート等は Phase 2/3 で対応。
- 音声データそのものの保存は行っていません。保存する場合は倫理審査・インフォームドコンセントの整備が前提です。
- `/api/submissions` (GET) は認証なしの簡易実装です。学外公開する場合はアクセス制御を追加してください。
- 本番運用時は HTTPS 環境でホスティングしてください(要件定義 5節)。

## 既知の制約

- 音声認識・マイク録音は Chrome 以外のブラウザでは動作しない場合があります(非対応時は警告バナーを表示)。
- 音量カーブと各単語の対応は、録音時間を単語数で均等分割した近似表示です。正確な単語境界にはフォーストアライメントが必要で、Phase 3の課題とします。
